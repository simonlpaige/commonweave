Contribute or correct

Know an organization, a useful connection, or something we got wrong? A small, specific contribution makes this directory more useful.

Start with what you know.

A small correction: correct a website or explain what an organization actually offers.

A short review: check three organizations in a local brief. Which roles fit? Which are missing?

One small project: help a network review its member directory, translate a field note, or test the map with an organizer.

Being listed does not mean an organization endorses Commonweave. Suggested connections need checking with the organizations involved.

Your contribution stays yours.

This form prepares a draft in your browser. It does not send it or change a listing. Download it without an account, or review it on GitHub before posting.

GitHub issues are public. Include public organizational information only. For removal or location protection, a listing name or ID and a short request are enough; do not explain a person's situation or add an address.

Be specific about the need, the proposed change, and what still needs checking. For a connection, name both organizations and distinguish an existing relationship from a possibility.

An official organization page or public source supporting this change. Leave private group invitations and personal profiles out.
