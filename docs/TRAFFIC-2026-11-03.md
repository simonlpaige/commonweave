# Discovery and distribution, November 3, 2026

The public site appeared in search results during this review; lack of indexing
is not an established explanation for low traffic. No analytics or Search
Console baseline was available, so visits, search impressions, click-through
rate and conversion are unknown. Other projects use the Commonweave name;
always include commonweave.earth and describe the knowledge base and map.

## Shipped entry point

`find-community-organizations.html` answers a concrete task: find organizations
for a community project, compare possible roles and check each lead. It links
to the knowledge base, existing map categories and the correction route. Home,
knowledge and README link to it; the sitemap includes it. Map category links
restore existing hash state rather than inventing new filters. It does not
claim verified services, introductions, current availability or partnerships.

Home, knowledge, map and the guide have complete social-preview metadata and an
original 1200×630 typographic card. Rebuild the PNG with
`python tools/build_share_image.py` (Pillow and installed Georgia/DejaVu Serif;
explicit font arguments are supported). The guide's copy button only writes
its public canonical link after a click. Its visible link works without JS or
clipboard permission. No tracking pixels, persistent visitor identifiers or
new analytics providers are introduced.

## Distribution experiment

Use the existing first marketing batch, revising its map walkthrough to point
to this guide. Keep six pending drafts total. Once access to an owned project
account is verified, publish one practical introduction, then the knowledge
base reading invitation and a worked food-role example on separate days, at
most three distinct updates per rolling week. State what each link lets a
reader do; avoid undifferentiated project announcements. Confirm public URLs.

For a community placement, first establish that its current rules welcome
project/resource sharing. Disclose authorship. Offer a useful answer or
specific exercise before a link; do not cross-post identical pitches. No
placement or external acceptance is established by this document. Retired
issue-tracker pitches and no-consent email contacts remain held. No paid spend.

## Measure and decide

The next bounded task is an owner-access check for Search Console or existing
first-party aggregate traffic data, followed by a dated 14-day baseline for
landing-page visits, search impressions/clicks and referrals, where available.
Do not install a new tracker merely to fill this table. Keep unknown values
unset. Record each actual placement, public URL, target page and resulting
evidence. Distinguish visitor acquisition from useful actions: a substantive
correction, a reported useful shortlist or a consenting test. Page views do not
satisfy the framework's participation test. Revise the message or destination
from observed evidence; do not infer demand failure from absent measurement.
