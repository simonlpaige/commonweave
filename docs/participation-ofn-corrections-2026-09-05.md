# Open Food Network: five Commonweave record corrections to review

Prepared 2026-09-05 for review by a Commonweave maintainer and, if useful, an OFN practitioner. This packet is complete locally and has not been sent or deployed. It concerns errors and gaps in Commonweave's own release, not a claim that OFN's directory is wrong.

**Finding:** five OFN instance records in [the shipped April release](../releases/organizations.json.gz) have no evidence URL or verification date; Belgium and Germany also have no website. The descriptions include launch dates or broad coverage claims that the sources checked here do not establish. A country instance is software infrastructure, not proof that a food provider delivers throughout that country.

**Method:** extract the five exact record IDs below from the release JSON; compare website and description against OFN's [official overview and local-instance links](https://openfoodnetwork.org/about-us/); open each linked national site. Four national sites returned content. Belgium could not be opened by the research tool, so only the global site's link was checked. This is field-specific evidence review, not blanket entity verification. No personal information, inventory, or bulk source-directory data was copied.

This is a source-link-only packet with original factual summaries, not an imported OFN catalog. The [German](https://openfoodnetwork.de/), [Canadian](https://openfoodnetwork.ca/), [Brazilian](https://openfoodbrasil.com.br/), and [US](https://openfoodnetwork.net/) site footers identify content as CC BY-SA 3.0 and code as AGPL 3. Those source terms are distinct from Commonweave's repository license. Any later content or dataset reuse needs its own scope and attribution review; this packet grants no relicensing permission.

## What this changes for discovery

For an organizer building a food project, these instances can be a **tool or network resource** alongside actual growers, a local hub, pickup/delivery capacity, storage, and an access/affordability mechanism. They should not fill all those roles themselves. Display the instance's link separately from location-dependent candidate providers. No new inter-organization edge is justified by these five website checks.

## A small optional question

For an OFN practitioner: does the distinction between “local instance,” “hub,” and “producer” match how you would want Commonweave to describe the work? The corrections can be accepted independently of any affiliation, endorsement, meeting, or data exchange.
